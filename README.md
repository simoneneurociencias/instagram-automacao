# Automação do Instagram

Responde automaticamente quem comenta uma palavra-chave nos posts de
[@sicarneironeurociencia](https://www.instagram.com/sicarneironeurociencia/):
manda o material pedido no Direct e responde o comentário.

Roda sozinho a cada 5 minutos pelo GitHub Actions. A fonte fica no projeto
principal; este repositório é a cópia que executa na nuvem.

Configuração: ver `AUTOMACAO.md`.

Os tokens ficam em Secrets do repositório, nunca no código.
